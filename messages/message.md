# Welcome to the Patcher v3!

Thanks for sticking around! v3 marks yet another milestone in updates and functionality the Patcher has received to date. It's now more organised and with more functionality exposed, as well as much less error prone.

It comes with the flagship feature of a complete rewrite of how patching works, which hopefully should rely less on manually acquired patterns and instead relying on automatically determining what it needs based off of an initial analysis of the binary file.

## What's new

- **Keeps up with game updates.** The Patcher finds what it needs in the game executable by itself.
- **GOG support**, plus **Generic** for anything else (Heroic, Lutris, Bottles…).
- **Patch from any OS.** It works out whether your game is the Windows or Linux version.
- **Easier cleanup** with **Delete Backups** and **Manage Save Backups**.
- A progress bar, a tidier options window, a more reliable **Fix Save**, and a new **?** button with quick tips.

## Already using the Patcher?

The welcome guide has been rewritten for v3. Open it any time from the options, under **General Utilities → Show Welcome Dialog**.

Happy Hunting!
